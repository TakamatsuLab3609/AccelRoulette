# 加速ルーレット

クリックで回す、手動操作のルーレットです。
左クリックで加速、右クリックで減速。放っておくと摩擦でだんだん遅くなり、止まったところが当選です。

- ボタンひとつで勝手に回る「ランダムルーレット」ではなく、**自分の手で回す** ルーレット
- 項目はテキスト欄に **改行区切り** でまとめて入力
- **同じ文字列は同じ色**（重複して書くと、その項目の当たる確率が上がります）
- 効果音は 5 種類のテーマから選べて、音ごとに ON/OFF・音量調節も可能
- ビルド不要。HTML / CSS / JavaScript だけで動くので、GitHub Pages にそのまま置けます

## 遊び方

| 操作 | 動き |
| --- | --- |
| 盤を **左クリック** | 加速（いつでも何回でも押せます） |
| 盤を **右クリック** | 減速（ブレーキ） |
| `Space` / `↑` | 加速（盤を選択中は `Enter` でも可） |
| `↓` | 減速 |
| スマホ：盤を **タップ** | 加速 |
| スマホ：**減速ボタン** | 減速 |

- 止まると結果がポップアップで表示され、履歴に記録されます
- ポップアップから「この項目を除外」を押すと、当たった項目をリストから消せます（直後なら「元に戻す」も可能）
- 止まる直前の数秒はドラムロールが鳴ります

## 設定

「操作」タブで変更できます。変更は自動で保存されます。

| 設定 | 初期値 | 説明 |
| --- | --- | --- |
| 加速量 | 20 rpm | 左クリック 1 回で上がる回転数（上限なし） |
| 減速量 | 20 rpm | 右クリック 1 回で下がる回転数（上限なし） |
| 自然減速 | 5 | 摩擦の強さ。0 にすると減速せず回り続けます（右クリックでのみ止まる） |
| 最高速度 | 300 rpm | これ以上は速くなりません。**0 にすると無制限**（上限なし） |
| 長押しで連打 | オフ | オンにすると、押しっぱなしで加速・減速が続きます |
| 連打の速さ | 8 回/秒 | 長押し中、1 秒あたり何回分クリックしたことにするか |
| 当選したら自動で除外 | オフ | 結果を閉じると、当たった項目が自動でリストから消えます（抽選向け） |

自然減速は「一定の減速」と「速いほど強くかかる減速」を組み合わせています。
初期値（5）で 100 rpm から約 12 秒、300 rpm から約 25 秒で止まります。

加速量・減速量・最高速度に上限はありません（`1e9` のような指数表記も入力できます）。
速くなるほど盤はぶれて見え、約 1,400 rpm を超えると色が混ざり合った見た目になります。
速度計は 10 万を超えると「12.3万」「4.5億」のように表示されます。

## サウンド

音源ファイルは使っておらず、すべて Web Audio API でその場で合成しています。
そのため音声ファイルの著作権を気にせず公開できます。

| テーマ | 雰囲気 |
| --- | --- |
| クラシック | 木と真鍮の盤。パチパチ鳴る針と拍手 |
| カジノ | 転がるボールとチップの音、ジャックポット |
| レトロゲーム | ピコピコ 8bit、矩形波のファンファーレ |
| クイズ番組 | ドラムロールとシンバル、ジャジャーン |
| 和風 | 木魚の針、太鼓の加速、鈴と琴で当選 |

「サウンド」タブでは、音量・ミュートのほか、次の音を個別に ON/OFF できます。

- カチカチ音（針がピンを越えるたび）
- 加速音 / 減速音
- 回転音（速さに合わせてうなる）
- ドラムロール（止まる直前）
- 当選音

> ブラウザの仕様で、最初にページをクリック（タップ）するまで音は鳴りません。
> iPhone はマナーモード（消音スイッチ）がオンだと音が出ない場合があります。

## データの保存

項目・設定・履歴はブラウザの `localStorage` に保存され、次に開いたときに復元されます。
サーバーには何も送信しません。別のブラウザや端末とは共有されません。

## ファイル構成

```
.
├── index.html   … 画面の骨組み
├── style.css    … 見た目（ライト / ダーク両対応）
├── script.js    … ルーレット本体（回転の物理・描画・操作・保存）
├── sounds.js    … サウンドエンジン（効果音の合成）
└── README.md
```

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成し、このフォルダの中身をそのままアップロード（または push）します
   ```bash
   git init
   git add .
   git commit -m "first commit"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
2. リポジトリの **Settings → Pages** を開きます
3. **Build and deployment** の Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ローカルで試すだけなら、`index.html` をブラウザで開くだけで動きます。

## カスタマイズ

- **最初に入っている項目**：`script.js` の `DEFAULT_ITEMS`
- **設定の初期値**：`script.js` の `DEFAULTS`
- **入力できる値の範囲**：`script.js` の `LIMITS`
- **効果音**：`sounds.js` の `THEMES`。テーマを 1 つ追加すると、画面の選択肢にも自動で出てきます
- **色・フォント**：`style.css` 冒頭の `:root` の変数

最新版の Chrome / Edge / Firefox / Safari（PC・スマホ）。
